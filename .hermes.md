# Hermes context: Liminal Commons Calendar Gateway

You are helping Erik build the Liminal Commons calendar via a Telegram bot gateway.

## What this project does

- Telegram bot receives Erik's messages.
- Messages are logged to SQLite at `data/gateway.db`.
- Agents (Claude Code, OpenCode, Hermes) can be triggered by Erik.
- Agents edit the repo and report back.

## How to work here

- Run the bot with: `python bot.py` (after `cp .env.example .env` and adding token).
- Use Docker with: `docker compose up -d --build`.
- Dev helpers: `make up`, `make logs`, `make test`.
- Add new agent dispatchers in `bot.py` under `AGENTS`.
- Keep project docs in sync when architecture changes.

## Constraints

- No hardcoded secrets.
- Cross-platform: Windows host + Linux Docker.
- Agent CLIs may not exist inside Docker; graceful fallback required.
